# 🎮 My First Prototype Game

> My first game prototype created while learning game development with Unity.

Game prototype pertama saya dalam perjalanan belajar **Game Development**.  
Project ini dibuat sebagai tempat untuk mengasah skill programming, game mechanics, dan penggunaan Unity.

## 📌 About The Game

Game ini masih berupa **prototype**, jadi jangan berharap langsung menemukan game AAA di sini wkwk 😆

Beberapa hal yang sudah saya pelajari dan implementasikan dalam project ini:

- 🎮 Player movement
- 🕹️ Player interaction
- 🧩 Basic game mechanics
- 🎥 Camera system
- 🗺️ Basic level/map
- 💻 C# scripting
- 🛠️ Unity workflow

> ⚠️ **Warning:** Game masih dalam tahap prototype.  
> Beberapa fitur dan sistem masih belum selesai atau masih memiliki bug.
